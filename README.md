## Highlights


- ### 제품 기획부터 출시까지

  팀에서 PM을 주로 맡으면서 chak의 상세 촬영 화면도 개발했습니다. 16:9 미리보기를 개선하고, 별도 사진 선택 단계 없이 상품 정보를 입력하도록 연결했습니다. 공식 사이트의 반응형 화면을 Astro·TypeScript로 만들고 GitHub Actions로 배포를 자동화했습니다.

- ### 카메라와 영상 전송

  개인 프로젝트 REC:ON에서 iPhone의 영상 캡처·HEVC 인코딩을 확인하고, 두 시뮬레이터에서 Bonjour 기기 발견과 TCP 연결을 검증했습니다. 실기기 간 원격 미리보기와 녹화는 미검증 상태입니다.

- ### iPhone 카메라의 노출 제어

  soprize의 카메라를 개발하며 당시 사용한 고정 조리개 iPhone에서는 셔터 속도와 ISO로 노출을 제어한다는 점을 배웠습니다. 이후 iPhone 18 Pro의 물리 가변 조리개와 AVFoundation의 제어 API를 살펴보며, 기기별 하드웨어가 촬영 기능의 설계 범위를 어떻게 바꾸는지 확인했습니다.

- ### 촬영 후 작업 흐름

  soprize에서는 2:3 프레이밍 결과를 편집 화면에 연결했고, 오래입자구에서는 SwiftData로 의류 관리 영수증을 저장하고 다시 불러오는 흐름을 구현했습니다.
